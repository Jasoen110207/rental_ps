# Konsep logo Tambah Bang

Dua alternatif desain awal untuk rental PS Tambah Bang. Hanya untuk peninjauan konsep; tidak diterapkan ke website.

## 01 — Plus Play

File: `01-tambah-bang-plus-play.png`

Simbol stik dengan tombol tambah menghubungkan aktivitas bermain dengan nama Tambah Bang. Tulisan tegak dan bentuk yang lebih sederhana membuat arah ini cocok untuk identitas utama. Rekomendasi awal: konsep 01.

## 02 — One More Round

File: `02-tambah-bang-one-more-round.png`

Tulisan arcade yang dinamis dipadukan dengan balon percakapan bertanda tambah, terinspirasi ucapan “Tambah, Bang!”. Arah ini lebih ekspresif untuk stiker atau identitas komunitas bermain; detail garisnya perlu disederhanakan jika kelak digunakan sangat kecil.

## Catatan

- Format PNG dengan transparansi, hasil eksplorasi imagegen; bukan master vektor final.
- Arah warna: biru kobalt, oranye, dan navy, mengikuti palet website.
- Nama pada kedua konsep: TAMBAH BANG. Deskriptor: RENTAL PS.
- Ejaan dan komposisi diperiksa secara visual; ukuran file dan kanal transparansi diperiksa setelah penyimpanan.
- Panduan konsep: [Logo Design skill](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md).
- Penyempurnaan geometri, versi satu warna, dan pengujian ukuran kecil dapat dilakukan setelah salah satu arah dipilih.
